# Archived iitletterProf Files

**Archived:** 2026-08-24  
**Delete after:** 2027-08-24

These files are superseded by `iitletterProf.cls` v2.7 and its current templates. This directory is outside `texmf`, so TeX does not discover the archived class versions during normal class lookup.

- `iitletterProf_v_1.cls` — original professor-letter class.
- `iitletterProf-v2-2.cls` — later pre-v2.7 class snapshot despite its imprecise filename.
- `IITLetterTemplate.tex` — superseded combined biography/bibliography template.
- `IITProfLetterTemplate_v_2.tex` — superseded template.
